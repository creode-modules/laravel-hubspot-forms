# What is it?
Laravel HubSpot Forms is an easy way to integrate your Laravel application to HubSpot using their API or embedded forms.

This package also provides a wrapper around the 1st party [HubSpot API PHP Library](https://github.com/HubSpot/hubspot-api-php), which makes it easiser to interact with the HubSpot API.

The API wrapper currently provides fucntionality to:
- Create a Contact
- Creast a Companie
- Create a Note
- Assign an Owner to a Conact
- Assign a Conatct to a Company
- Assign a Note to a Contact

Alternatively, a HubSpot embedded form can be added to you Laravel application using the provided **Blade component**.
